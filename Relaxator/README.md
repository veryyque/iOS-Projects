# 🌿 Relaxator – Релаксатор

**Мой первый достаточно большой Pet-проект на iOS, который находится в активной доработке.**  
Приложение помогает расслабиться, сосредоточиться или быстрее уснуть под успокаивающие звуки природы.

---

## 🚧 Статус проекта

✅ Базовый функционал реализован  
🔄 В разработке: новые звуки, визуальные эффекты, база данных пользователей  

---

## ✨ Текущий функционал

- 🎵 **5 расслабляющих звуков** (дождь, огонь, ветер, etc.) – включаются по нажатию кнопки
- 😴 **Режим «Сон»** – встроенный таймер, автоматически отключающий звук через заданное время
- 🔊 **Управление воспроизведением**:
  - Пауза / возобновление
  - Остановка
  - Регулировка громкости прямо в приложении

---

## 📈 Планы по развитию

- 🖼️ **Динамические фоны** – для каждого звука отдельный экран с анимированной картинкой, соответствующей аудиодорожке
- 🌊 **Новые звуки** – расширение библиотеки релаксирующих аудио
- 👤 **Пользовательская база данных**:
  - Регистрация / логин
  - Сохранение любимых звуков
  - Индивидуальные настройки
- 🎤 **Загрузка своих звуков** – возможность добавить собственные аудиофайлы прямо из приложения

---

## 🛠 Технологии

- **Swift** – язык разработки
- **SwiftUI** – построение интерфейса (верстка кодом)
- **MVVM** – Model - View - ViewModel паттерн
- **AVFoundation** – работа с аудио
- **UserDefaults** / **CoreData** (в перспективе) – хранение настроек
- **Auto Layout** – адаптивный дизайн под все экраны iPhone
